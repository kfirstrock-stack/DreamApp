# DreamApp

Живая история мест в фотографиях: карта + шкала времени до минуты.

## Запуск на телефоне

```
cd ~/project/DreamApp
npx expo start
```

Затем откройте DreamApp в **Expo Go** на телефоне (карточка в списке серверов или QR-код камерой).

- Если добавились картинки, шрифты или что-то «не подхватилось» — запускайте с очисткой кэша: `npx expo start -c`
- Чтобы применить изменения без перезапуска сервера: встряхните телефон → **Reload**
- Если Expo Go пишет «not signed in to Expo CLI»: `npx expo login`

## Стек

Expo (React Native) · Expo Router · Reanimated · Supabase (PostGIS)

## Демо-данные

Демо-авторы и снимки помечены в базе `is_demo = true`, картинки лежат локально в `assets/demo/` (в репозиторий не попадают). Перед релизом — удалить.

## База данных (Supabase)

- Проект: `xxuzjmjkgfjxmdqehvap` (регион eu-central-1, тариф Free — автобэкапов нет).
- `supabase/schema.sql` — справочная копия схемы: таблицы, RLS-политики, функции, триггеры, бакеты `photos` (публичный) и `photos-private`. Это копия для восстановления, не миграция: на живую базу не запускать как есть. После любого изменения схемы в Supabase — выгрузить заново и закоммитить.
- Ключи: в приложении только publishable-ключ (см. `.env.example`). `service_role` и пароль БД в репозиторий не попадают.
- Бэкап данных (таблицы в CSV и публичные файлы) делается вручную и хранится вне репозитория — в нём личные данные.
