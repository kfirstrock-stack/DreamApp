# DreamApp

Живая история мест в фотографиях: карта + шкала времени до минуты.

## Запуск на телефоне

```
cd ~/project/DreamApp
npx expo start
```

Затем откройте DreamApp в **Expo Go** на телефоне (карточка в списке серверов или QR-код камерой).

- Если добавились картинки, шрифты или что-то «не подхватилось» — запускайте с очисткой кэша: `npx expo start -c`
- Чтобы применить изменения без перезапуска сервера: встряхните телефон → **Reload**
- Если Expo Go пишет «not signed in to Expo CLI»: `npx expo login`

## Стек

Expo (React Native) · Expo Router · Reanimated · Supabase (PostGIS)

## Демо-данные

Демо-авторы и снимки помечены в базе `is_demo = true`, картинки лежат локально в `assets/demo/` (в репозиторий не попадают). Перед релизом — удалить.
